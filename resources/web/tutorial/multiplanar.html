Cut-plane and wave slicing

OrcaSlicer Custom Beta · Windows x64 · Experimental three-axis printing

Cut planes divide one model into sections that use different slicing directions. The model stays in one piece, and the nozzle stays upright. This fork writes ordinary XYZ moves; it does not control rotary axes.

Use preview and exported G-code for software testing first. The generic hotend model is not a measured clearance for your printer. Physical Bambu A1/P2S clearance and printing safety require separate validation before use.

1. Enable the printer setting

  1. Switch the settings view to Expert.
  2. Edit your printer preset. Open Basic information, then Non-planar printing.
  3. Enable Experimental non-planar slicing.
  4. Review the Hotend envelope radius, four hotend side angles, and the printer's extruder/gantry clearance settings. Do not treat their generic values as measurements of your machine.

Save a separate experimental preset to keep your usual Beta 5 settings available.

2. Set up a supported process

  • Choose By object print sequencing and use one printing filament.
  • Turn off the prime tower and spiral vase mode.
  • Set Raft layers to 0 and disable the draft shield. Brims and finite-height skirts are supported on the upright bed root; they do not repeat on elevated sections. Skirts stop when the root section finishes. For a minimal first software check, choose Skirt loops 0 and Brim type No-brim.
  • Keep the object's bottom section upright on the bed. Leave independent object/part build directions at their defaults; set upper section directions by tilting their cut planes.

Normal, classic-tree and organic supports can carry loads between cut-plane sections. Organic inherited supports require uniform layer heights. Floating section bases and build directions that differ from their supporting cut-plane normal are not supported. Timelapse parking and snapshots are omitted for non-planar sections.

3. Add a cut plane

  1. Load a model and select the whole object in Prepare.
  2. Open the Cut Planes toolbar tool.
  3. Move the plane through the model. For a first software check, use a 20 mm cube and a horizontal plane near its middle.
  4. Click Add cut plane and keep Enable cut planes checked. If offered, accept the change to By object sequencing.
  5. Enable Color cut chunks to inspect the partition. The original object is not destructively cut.

After checking a horizontal partition, tilt the upper section's plane by a small angle and slice again. The lower section stays upright; the upper section follows the cut-plane normal. Keep Automatic order enabled unless you need to author the dependency order yourself.

4. Slice and inspect

Click Slice and inspect all sections in Preview, including support contacts and moves between sections. Tilted layers vary in physical Z. Their slider ranges follow each section's local layer order.

Export checks the configured hotend envelope against already deposited material and checks section motion against the printer's printable area and height. A rejected file does not become exportable. A passing check covers the configured software model; it does not establish physical printer clearance.

Save the project as 3MF to retain the cut-plane list, including disabled planes.

Wave overhangs

In Expert mode, open the process settings at Quality → Overhangs and enable Experimental wave overhangs. The nearby controls are Wave line spacing, Wave overhang speed and Wave overhang fan speed. Optional Solid layers above wave overhangs reinforces infill above actual wave coverage. Zero keeps the normal shell settings; a positive value selects the number of following layers within the same section.

Wave overhangs can be tested on ordinary planar objects with non-planar slicing turned off. They generate traces on qualifying unsupported shelves; ordinary supported walls do not become waves. Inspect their paths and cooling before any physical test.

If slicing is refused

Message or symptomWhat to check
Cut Planes is unavailableSelect one object and enable the printer's Expert non-planar setting.
No enabled plane divides the objectMove the plane through printable material and add it to the list.
A setting combination is unsupportedUse By object sequencing, one filament, no prime tower/raft/vase/draft shield, and an upright bed root.
Floating base or incompatible build directionMake the section rest on its cut plane and let its direction follow that plane.
Hotend/gantry tilt limit exceededReduce the tilt or use gentler sections. Do not enlarge clearance values just to bypass a rejection.
Custom macro rejectedSection macros cannot extrude, home, reset XYZ coordinates, change motion limits, or conditionally move XYZ. The standard G92 E0 reset is supported in relative extrusion mode. They must restore absolute positioning and millimeters.
Collision or printable-area rejectionReview the reported move, model placement, cut-plane order and measured clearance model.
